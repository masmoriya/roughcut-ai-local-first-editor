Local data and uninstall
On macOS, RoughCut stores its SQLite library under
~/Library/Application Support/roughcut. That directory also holds
generated waveform and preview caches and joined media created
by Append Media. Preserve the whole directory while the app is closed
if you need to restore projects, transcripts, edit history, or joined
media. Removing the application leaves this data on disk. Removing the
data directory also removes the local library and any joined media
stored there. Original sources and manually exported files live at
their chosen paths. The standalone workflow uses Resolve's manual XML
import and requires no Resolve script installation.
Trashed projects can be restored from the project picker. On startup,
RoughCut purges projects that have been in the trash for over 30 days.
Diagnostic logs are stored separately in ~/Library/Logs/RoughCut when the
macOS home directory is available. They include platform and version
information and structured FFmpeg failure metadata, including the
operation, exit status and elapsed time. The FFmpeg failure event omits
process stderr. Removing the application also leaves that log directory
on disk.
